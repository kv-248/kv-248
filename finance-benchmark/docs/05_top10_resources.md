# Top 10 finance data sources

Shortlist from phase 1, ranked by priority to build. Web view: https://claude.ai/artifact/SXFq2qdnq8UXEpiVb38SrD
(GT = step checkable against a number the source itself reports.)

## Caveats that apply to all ten
1. **Only 5 of 10 are pulled and validated** (#1, #3, #4, #6, #7). #2 profiled only, #5 fund-level only, #9 schema only, #8 and #10 not pulled.
2. **Most primary sites were blocked in this sandbox.** Pulls used mirrors (public S3, Kaggle, GitHub, HF query API). A full build needs sec.gov, ffiec.gov, the HF file CDN, CourtListener etc. allowlisted (list in `03_source_catalog.md` §5).
3. **Mirrors are third-party.** Some state no licence, completeness varies; re-check against the primary source before release.
4. **Archive snapshots are frozen** (2020 PDF crawl, 2024–25 Data.gov archive, old Kaggle copies): fine for dev; test splits need live pulls. #3, #5, #6, #7, #9, #10 refresh monthly/quarterly.
5. **Scraping restrictions:** MSRB EMMA and Chapter 11 claims agents restrict scraping/redistribution, so hand-collect. Freddie/Fannie loan files, FINRA TRACE, NAIC need paid licences and are excluded.
6. **Source totals grade numbers only;** memos and judgment calls need a rubric or LLM judge.
7. **Some details come from web search,** marked "unverified" in `docs/sources/`.
